# 🖥️ Máquinas de Turing - Colección de Ejercicios

## 📝 Descripción
Este repositorio contiene una colección de ejercicios de Máquinas de Turing desarrolladas en Python, cada uno diseñado para resolver diferentes problemas y demostrar diversos conceptos de la teoría de la computación.

## 🚀 Características Principales
- Implementaciones visuales con interfaz gráfica moderna
- Código modular y bien documentado
- Visualización paso a paso de la ejecución
- Múltiples ejemplos de máquinas de Turing

## 💻 Máquinas Implementadas

### Sumador Binario
- Suma números en formato binario (ejemplo: 10+1=)
- Visualización en tiempo real del proceso
- Conversión automática entre binario y decimal
- Interfaz gráfica con tema personalizado

### Verificador de Paridad
- Determina si una cadena binaria tiene un número par o impar de 1's
- Interfaz visual para entrada binaria
- Validación en tiempo real de la entrada
- Resultado codificado por colores (verde para par, azul para impar)

### Validador de Patrón 'abb'
- Verifica si una cadena termina con el patrón 'abb'
- Interfaz intuitiva para entrada de cadenas
- Validación de entrada en tiempo real
- Resultado visual con códigos de color

## 🛠️ Requisitos
- Python 3.x
- Tkinter (incluido en la mayoría de las instalaciones de Python)
- TTK Themes (opcional para temas adicionales)
